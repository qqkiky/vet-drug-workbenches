## 一、国际工作台（USDA/EMA）

### 1.1 顶部与标题

| 现状（zh / en） | 建议 | 理由 |

| 「国际兽用生物制品监管追踪工作台」/「Veterinary Biologics Regulatory Tracker」 | 标题保留；h1 下方新增一行小字副标题：zh「美国 USDA/CVB · 欧盟 EMA/CVMP 获批产品」；en「USDA/CVB · EMA/CVMP approved products」 | 标题字面没问题，但缺少“查的是什么、覆盖哪两个机构”的即时说明，演示时第一眼更清楚 |

### 1.2 顶部操作按钮（同步/数据源区）

| 现状 | 建议 | 理由 |

## 三、数据内容质量（国际工作台，已确认做）

### 3.1 EMA（807 条）——活性成分词库统一补齐
- 现状：indication 字段填的是“活性成分”（如 Oxytetracycline），不是适应症；部分产品名混入希腊语 / 东欧语言后缀。
- 做法：
  1. 统计全部唯一活性成分（预计几十种：阿莫西林、美洛昔康、多拉菌素、氟雷拉纳…）；
  2. 建立「成分 → 适应症」词库（中英双语，含适用物种，参考国内词库与药理资料）；
  3. 产品名英文规范化：品牌名 + 英文剂型保留，剥离非英文字段；
  4. 一次性重写这 807 条，写入数据库并重新发布。
- 兜底：词库未覆盖的冷门成分标注「适应症待补充（Ingredient: X）」，不硬编。

### 3.2 USDA（62 条）——清理与去重
- 现状：indication 与产品名几乎相同（对疫苗即“预防对象”描述，可接受）；个别诊断试剂记录混入 PDF 表格垃圾（如 "502A.00 373 671…"）。
- 做法：清洗垃圾字符与重复片段；对诊断类把“Test Kit”描述整理成可读用途文本；保留英文原文（USDA 为英语数据，中文侧展示时保持英文并在表头注明）。

### 3.3 展示层
- 适应症列允许换行展示完整文本，移动端卡片内可展开/收起长文本，避免截断误导。
